# Dog Breed Detection (Streamlit)

ระบบตรวจจับสายพันธุ์สุนัข (ชิสุ, เฟรนช์บูลด็อก, โกลเด้นรีทรีฟเวอร์) ด้วย YOLO — แปลงมาจากเวอร์ชัน Flask เดิม

## โครงสร้างโฟลเดอร์

```
streamlit_app/
├── app.py
├── requirements.txt
├── model/
│   └── best.pt          <- โมเดลที่เทรนไว้แล้ว
├── upload/               <- ไฟล์วิดีโอที่อัปโหลดจะถูกเก็บที่นี่อัตโนมัติ
└── .streamlit/
    └── config.toml       <- ธีมสีดำ-น้ำเงิน (ไม่ใช้ CSS)
```

## วิธีติดตั้งและรัน

```bash
pip install -r requirements.txt
streamlit run app.py
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8501`

## ฟีเจอร์

- **แท็บอัปโหลดวิดีโอ**: อัปโหลดไฟล์วิดีโอ (mp4/avi/mov/mkv) ระบบจะบันทึกไว้ในโฟลเดอร์ `upload/` แล้วรันตรวจจับ+ติดตาม object พร้อมแสดงผลแบบเฟรมต่อเฟรม พร้อม progress bar
- **แท็บเว็บแคมเรียลไทม์**: เปิดกล้องเว็บแคมของเครื่องที่รันแอป (ต้องรันแอปบนเครื่องที่มีกล้องต่ออยู่ ไม่ใช้งานได้บน cloud ที่ไม่มีกล้อง)
- ปรับ **confidence threshold** ได้อิสระในแต่ละแท็บ
- ธีมสีดำ-น้ำเงินตั้งค่าผ่าน `.streamlit/config.toml` ล้วนๆ ไม่มีการฝัง CSS ใดๆ ในหน้าเว็บ

## หมายเหตุ

- ปุ่ม "หยุด" ของเว็บแคมในเวอร์ชันนี้ใช้ checkbox ธรรมดา ซึ่ง Streamlit จะประมวลผลจริงหลังจากลูปปัจจุบันจบ — หากต้องการปุ่มหยุดที่ตอบสนองทันทีระดับ production แนะนำให้ปรับไปใช้ไลบรารี `streamlit-webrtc` แทน `cv2.VideoCapture` ตรงๆ
- หากต้องการ deploy ขึ้น Streamlit Community Cloud ฟีเจอร์เว็บแคมจะใช้ไม่ได้ เพราะเซิร์ฟเวอร์ cloud ไม่มีกล้อง ต้องใช้ `streamlit-webrtc` ที่ดึงภาพจากกล้องฝั่ง browser ของผู้ใช้แทน
